# Reconstructed project history

Git was introduced after development. These commits import surviving files and mark their known scope. Commit dates are import dates. The archive does not assert a historical branch graph.

- The main line collects component snapshots used by the current release, then the reproducible distribution.
- A snapshot records component files and their hashes. An individual component generally requires its matching game baseline and other packages.
- Experimental branches are isolated, including versions superseded or excluded from the current distribution.
- Source models, complete game exports, saved games, machine configuration and build caches remain outside the Git repository.
